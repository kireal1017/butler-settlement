# 등기부등본 샘플 픽스처

## 각 샘플이 갖춰야 할 것

한 이미지(또는 연속 페이지) 안에 **아래 셋을 모두** 포함해야 파서를 완성할 수 있습니다.

1. **헤더 줄** — `[집합건물] <주소> 제N동 제N층 제N호` + `고유번호 ####-####-######`
2. **【 표 제 부 】( 전유부분의 건물의 표시 )** — 전용면적 `##.##㎡` 포함
3. **【 갑 구 】** — `소유자 <성명>` 이 들어간 소유권이전 행

> ⚠️ 1동 건물 표시에도 면적이 여러 개 나옵니다. 파서는 **전유부분 섹션을 먼저 잘라낸 뒤**
> 면적을 찾으므로, 전유부분 표제부가 반드시 들어가야 합니다.

## 만들 변형

| 파일 | 내용 | 기대 결과 |
|---|---|---|
| `sample-a.png` | 단독 소유, 정상 | `matched` |
| `sample-b.png` | 공유자 2인 (지분 표기) | `matched` |
| `sample-c.png` | 소유자가 임대인과 다른 이름 | `name_mismatch` |
| `sample-d.png` | 을구에 근저당 포함 (노이즈) | `matched` |

- 해상도 **가로 1600px 이상**, 그레이스케일 이상
- 실제 개인정보를 쓰지 말고 가상의 성명·주소를 사용

## 같이 만들 파일

각 이미지마다 두 개를 함께 둡니다.

```
sample-a.png                 원본 이미지
sample-a.expected.json       정답 (파서 테스트 기준)
sample-a.png.txt             OCR 원문 (픽스처 모드용 — 키 없이 개발·테스트)
```

### expected.json 형식

```json
{
  "address": "서울특별시 양천구 목동 300-130",
  "dong": "17",
  "floor": "1",
  "ho": "101",
  "uniqueNo": "1234-5678-901234",
  "exclusiveArea": 84.95,
  "owners": ["김성호"],
  "expectedMatch": "matched"
}
```

### png.txt 만드는 법

외부 OCR을 **한 번만** 돌려서 나온 원문 텍스트를 그대로 저장합니다.
그 뒤로는 `OCR_PROVIDER` 없이도 파서 개발·테스트가 무료로 반복 가능합니다.
